# Studio Lot backdrop

Drop your lot render here and the homepage uses it automatically:

- `lot.mp4`  — a living lot loop (preferred; muted, autoplay, loop). Best from Kling.
- `lot.jpg`  — a still lot image (fallback if no video).

Requirements:
- 16:9, landscape, NO UI / text / captions baked in (the app overlays its own).
- Dark, cinematic, golden-hour dusk to match the studio aesthetic.

If neither file is present, the lot falls back to the built-in cinematic scene.
