# Studio room images (Explore the Studio glass panel)

Drop a photographic image for each room here. Filenames must match exactly
(the app maps each room to <slug>.png):

- writers-room.png      — Writers Room (Develop Stories)
- character-dept.png    — Character Dept. (Build Legends)
- art-department.png    — Art Department (Create Worlds)
- production.png        — Production (Bring to Life)
- post-production.png   — Post Production (Shape the Cut)
- distribution.png      — Distribution (Share the Story)

Recommended: ~landscape 4:3, dark/cinematic, NO text baked in (the app overlays
the room name + subtitle). Until a file exists, the card shows a gold-icon
placeholder.
